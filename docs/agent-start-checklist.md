# Agent Start Checklist

Before implementation work, run this checklist.

1. Read root `AGENTS.md`.
2. Read `docs/README.md`.
3. Classify the task using `docs/task-routing.md`.
4. Read every relevant folder-level `AGENTS.md`.
5. Read the required docs for the task type.
6. Use a matching `docs/templates/` template when available.
7. Identify whether the task touches shared/server/client contracts together.
8. Identify whether docs, Arcawiki, localization, theme, permissions, audit, cleanup, or tests must change.
9. Check `docs/commands.md` for the right verification commands.
10. Check `docs/folder-structure.md` before adding or moving folders.
11. In the final report, state what was read, what was changed, what checks ran, what was skipped, and remaining risks.

If the task is ambiguous, destructive, or changes gameplay architecture, restate the task and wait for confirmation before editing.
