# Architecture Decision Records

Use ADRs for major decisions.

Create an ADR when changing:

- architecture,
- API/WS protocol,
- world model,
- scenario format,
- persistence,
- AI architecture,
- dependency policy,
- security model,
- region/province model.

ADRs are short records of context, options, decision, and consequences. Use `ADR-0001-template.md` as the template and increment the number for new decisions.
