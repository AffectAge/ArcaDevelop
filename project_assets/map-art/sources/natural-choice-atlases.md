# Каталоги природных объектов для выбора

Все листы ниже — самостоятельные **4×4** PNG-каталоги с настоящим alpha-каналом.
Чёрный цвет в предпросмотре редактора означает прозрачную область, а не является частью
текстуры. Объекты не содержат хромакея, подложки земли или общей фоновой тени.

Координата кадра задаётся как `R<строка>C<столбец>`: `R1C1` — верхний левый объект,
`R4C4` — нижний правый. Например: `natural-choice-mountain-ridges-4x4.png — R2C3`.

| Лист | Содержимое |
| --- | --- |
| `natural-choice-temperate-trees-4x4.png` | Умеренные лиственные и смешанные деревья |
| `natural-choice-northern-tundra-4x4.png` | Северные хвойные, низкая растительность и камни |
| `natural-choice-tropical-trees-4x4.png` | Тропические деревья, пальмы и густая растительность |
| `natural-choice-desert-oasis-4x4.png` | Пустынные кусты, пальмы, кактусы и оазисные объекты |
| `natural-choice-wetland-mangrove-4x4.png` | Камыши, болотные кусты и мангры |
| `natural-choice-shrubs-undergrowth-4x4.png` | Кустарники и подлесок |
| `natural-choice-snow-ice-4x4.png` | Снег, лёд и морозные скальные объекты |
| `natural-choice-mountains-rocks-4x4.png` | Одиночные горы, пики, осыпи и скальные выходы |
| `natural-choice-mountains-snow-4x4.png` | Горы: голые скалы, заснеженные пики, ледяные хребты, вулканические и пустынные варианты |
| `natural-choice-mountain-ridges-4x4.png` | Горные хребты и протяжённые скальные гряды |
| `natural-choice-hills-4x4.png` | Низкие травянистые холмы и возвышенности |
| `natural-choice-rocky-hills-4x4.png` | Скалистые холмы, утёсы и низкие каменистые гряды |

Эти каталоги служат для художественного выбора. Они пока не входят в runtime-манифест
и не меняют текущие игровые атласы до отдельного решения о том, какие кадры принять.
