# Asset Agents

Always start from root `AGENTS.md` and `docs/README.md` before using this folder guide.

Use this guide for `project_assets`.

Project assets are source/reference material. Scenario-owned runtime uploads belong under the active scenario assets structure, not here.

Rules:

- Do not edit or delete large/source assets unless explicitly requested.
- Do not use global assets to hide missing scenario-owned files.
- When an asset is tied to a scenario entity, document its owner and cleanup lifecycle.
- Removed mechanics or deleted entities must not leave obsolete referenced assets.
